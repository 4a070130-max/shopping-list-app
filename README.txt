購物清單 PWA — 第一版功能原型

使用方式：
1. 將本資料夾部署至支援 HTTPS 的靜態網站空間。
2. 使用 iPhone Safari 開啟網址，選擇「分享」→「加入主畫面」。
3. 首次載入需網路；離線使用須先成功快取程式檔案。

已具備：購物計畫／分類／店家／商品、單張壓縮照片、一般與伴手禮顏色、商品詳細頁、搜尋、字體大小、背景上傳、伴手禮進度、回購標記、最近刪除、匯出商品長圖、行事曆 ICS。

目前限制：
- 這是可操作的第一版原型，不是正式上架版。
- 資料使用 localStorage，容量有限；大量圖片仍可能超過限制。正式版應改用 IndexedDB。
- 字體目前僅為系統字型替代，尚未嵌入選定的中英日開源字型。
- 觸控拖曳排序在部分手機瀏覽器可能不支援；後續應加專用觸控排序。
- 行事曆檔案能否直接匯入 iPhone 行事曆，依 iOS 版本與分享方式而異。
- 尚未實作多收件人、批次回購複製、完整語言切換、離開前未購提醒彙總、資料匯入匯出。
- 不應把本機資料當作永久備份；清除瀏覽器網站資料會遺失。
