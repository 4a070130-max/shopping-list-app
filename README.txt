購物清單 PWA v2 — 修正版（2026-10-14）

上傳更新方式（iPhone Safari）：
1. 先在舊版「一般瀏覽」中確認有無要保存的資料；v1 的儲存格式不明，v2 無法保證自動移轉舊資料。
2. 在 GitHub 的 shopping-list-app 專案上傳本資料夾內的 index.html、manifest.webmanifest、icon.svg、sw.js 與 icons 資料夾內全部 20 張 PNG，取代原本同名檔案。務必保留 icons/ 的資料夾結構。
3. Commit changes 後，等 GitHub Pages 部署完成，使用 Safari 一般瀏覽模式重新開啟網站；若仍看到舊畫面，重新整理一次。
4. 網站網址不變。正式使用前，新增測試資料，切換分頁、重整、關閉再開啟，確認資料仍在。

本版重點：
- IndexedDB 本機儲存，操作後立即寫入；新增 JSON 備份匯入匯出。
- 資料夾刪除確認、7 天最近刪除與還原；上移下移排序。
- 第二層分類及依分類推薦店家，底部選單可上下滑動，自訂仍可打字。
- 任意資料夾可直接新增商品，不強迫建立第三層。
- 商品卡片整片分類顏色、照片貼齊卡片；20 款完成圖示可選。
- 一般／伴手禮商品，伴手禮購買數量進度、完成清單。
- 可愛字體為 iPhone 裝置可用字體替代，不是先前討論的授權字體。

注意：
- GitHub Pages 網站是公開的；請勿把私人購物資料寫入 GitHub 原始碼。商品與設定儲存在瀏覽器本機。
- 私密瀏覽不適合長期保存。不同瀏覽器或網站資料分開儲存；清除網站資料可能造成遺失，請定期匯出 JSON 備份。
- 本版尚未提供真正的 iPhone 背景通知、地理圍欄提醒、完整長圖匯出、跨裝置同步、多收件人分配及真正拖曳排序。
- 圖示為已確認的 20 款圖稿裁切成透明背景 PNG。
